= Which Polaris items DCB offers to other libraries
:description: The Polaris item flags and Host LMS settings that decide whether DCB offers an item for consortial borrowing.

DCB reads each item through the PAPI item list for its bib. Several things can stop it offering
an item to other libraries.

== Flags DCB reads from the item

[cols="1,3",options="header"]
|===
| Item flag | Effect

| *Display in PAC* off
| The item is suppressed: it is not shown or offered.

| *Loanable outside system* off
| The item is given the loan policy `NO_LEND` and is not offered. This is the flag for items a
library lends to its own patrons but not to other libraries. PAPI sends it as
`LoanableOutsideSystem` in the item list for a bib (seen on Polaris 8.1). If a Polaris version
leaves it out, the item is offered and only the settings below keep it back.

| *Holdable* off
| The item is given the loan policy `NO_LEND` and is not offered. Polaris would refuse DCB's hold anyway.

| *Non-circulating* on
| The item is given the loan policy `NO_LEND` and is not offered.
|===

Ask libraries to use *Loanable outside system*, not *Holdable* or *Non-circulating*, to keep an
item out of DCB: the other two also stop the library's own patrons borrowing it.

== Host LMS settings

[cols="1,3",options="header"]
|===
| Setting | Effect

| Item suppression ruleset
| A rule matching the item hides it. A rule can test any field of the PAPI item, including
`ShelfLocation`, `CollectionName` and `MaterialType`, so "every item on the Front Desk shelf" is
one rule.

| `shelfLocationPolicyMap`
| Maps a shelf location to a loan policy. `NO_LEND`, `LOCAL_ONLY` and `REFERENCE_ONLY` are not
offered. `GENERAL` and `SHORT_LOAN` are. A shelf location that is not in the map is `GENERAL`.
|===

A library that keeps the items it never lends outside its system on their own shelf locations or
collections needs only one rule or one map entry for all of them.
