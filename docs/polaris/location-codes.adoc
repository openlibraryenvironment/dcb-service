= How DCB reads a Polaris item's location
:description: What the location code of a Polaris item is, what it is used for, and where shelf-level rules belong.

== The location code is the branch

For a Polaris item, DCB's location code is the item's branch (`LocationID`), and the location
name is its shelf location (in `Legacy` mode) or its branch name (in `LocationId` mode). This has
been so since v8.16.0, and it is deliberate: the code is how DCB finds which library an item
belongs to.

[cols="1,3",options="header"]
|===
| `item.item-agency-resolution-method` | How DCB finds the item's library

| `Legacy` (default)
| Looks the location code (the branch id) up in the Host LMS's `Location` mappings, falling back to
a `*` mapping. The Host LMS's default agency is used only for an item with no location at all.

| `LocationId`
| Looks the branch id up in the Host LMS's `Location` mappings. There is no fallback: an item at a
branch with no mapping has no library and is not offered. Map every branch id before choosing this.
|===

Because the code is the branch, a `Location` mapping cannot tell one shelf from another. A mapping
keyed on a shelf location number (say, shelf 9 for New items) never matches: every item at that
branch reads as the branch's id.

== Where shelf-level rules belong

Use one of these, which read the shelf location directly:

* `shelfLocationPolicyMap` on the Host LMS, keyed on the shelf location *name* exactly as Polaris
shows it. Valid values are `GENERAL`, `SHORT_LOAN`, `REFERENCE_ONLY`, `LOCAL_ONLY` and `NO_LEND`;
items under the last three are not offered to other libraries. Any other value, such as
`REFERENCE`, is read as `UNKNOWN`, is offered, and raises the alarm
`ILS.<host LMS code>.POLARIS_INVALID_SHELF_LOCATION_POLICY`.
* An item suppression rule testing `ShelfLocation`, `CollectionName` or `MaterialType`, which hides
the item altogether.

Before this release, DCB recorded the policy from the map but did not act on it, so items mapped
to `NO_LEND` or `LOCAL_ONLY` were still offered. They are not offered now. See
xref:what-is-lent.adoc[Which Polaris items DCB offers to other libraries].
