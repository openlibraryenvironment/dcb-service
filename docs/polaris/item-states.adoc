= Item states DCB asks Polaris to set
:description: Which item states DCB sets in a Polaris library during a request, and what happens with the rest.

During a request, DCB asks each library system to set the state of an item. In Polaris:

[cols="1,3",options="header"]
|===
| State | What DCB does in Polaris

| Available | Sets the item's circulation status to Available.
| In transit | Checks the item in at the virtual item branch, which puts it in transit.
| Received, Completed | Nothing. DCB sends these in every request; Polaris's own check-in has already done what they mean. Logged at DEBUG.
| Off-site, Missing, On hold shelf | Nothing, and the request carries on. DCB does not send these to Polaris today. If it ever does, DCB raises the alarm `ILS.<host LMS code>.POLARIS_UNSUPPORTED_ITEM_STATE`, naming the state.
|===

A state added to DCB later cannot reach Polaris unhandled: the adapter lists every state without
a catch-all, so the build fails until the new one is handled.

Before this release, every state Polaris does not set was logged as an ERROR, about 8,300 times
at MOBIUS between August and October 2026, although nothing was wrong.
